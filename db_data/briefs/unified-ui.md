## Context

The Lab grew one screen at a time, and it shows.

Each page was built when it was needed, with the spacing, the colours and the components that seemed right that week. Nothing is broken — but a contributor who moves from the leaderboard to a challenge to their profile crosses three products, and has to relearn where things are each time.

This challenge gives the app one vocabulary: one scale, one set of tokens, one component per job, and pages that are assembled rather than drawn.

## Objective

What has to be shipped:

- A token set — colour, type, spacing, radius — that every screen reads from, with no hard-coded value left in a page.
- The shared components the app actually needs: card, pill, avatar, empty state, drawer.
- The existing screens migrated onto them, one by one, without changing what they do.

## Expected result

- A pull request from your branch, with the board reflecting what it contains.
- A before/after on at least three screens, and the list of the ones still left to migrate.

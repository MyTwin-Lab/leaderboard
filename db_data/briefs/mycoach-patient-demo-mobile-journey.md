## Context

Rehabilitation mostly happens between appointments, when the patient is alone at home. MyCoach is the demo of a mobile patient journey: today's session, the prescribed exercises, a guided session driven by on-device pose estimation, then the replay of the movement.

## Objective

Build the web demo of the patient journey in six screens: home and today's session, exercise list, live session with pose estimation, end-of-session summary, replay with a timeline, and history.

Everything is local to the browser — the demo has no backend.

## Expected result

- The application deployed and publicly reachable, so a validator can walk through it.
- The repository, with a README describing the journey screen by screen.
